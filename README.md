# TalentMatch – Resume Analyzer

TalentMatch is a Python-based web application built with Streamlit that helps job seekers analyze their resumes against job descriptions.

Features

- **User Authentication:** Sign up and log in to the application.
- **PDF Resume Upload:** Upload a resume in PDF format.
- **Job Description Matching:** Compare resume content with a job description.
- **Skill Gap Analysis:** Identify matching and missing skills.
- **Resume Improvement Suggestions:** Get rule-based recommendations to improve your resume.
- **Analysis History:** View previous resume analyses.
- **Downloadable Reports:** Download analysis results as a text report.
- **Interactive UI:** A modern interface built with Streamlit.

Technologies Used

- Python
- Streamlit
- SQLite
- Scikit-learn
- PyPDF

Installation and Setup

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

5. Open the local URL displayed in your terminal.

 How It Works

1. Create an account or log in.
2. Upload your resume as a PDF.
3. Enter the job description.
4. Analyze the resume.
5. Review the matching score, skill gaps, and improvement suggestions.
6. Download the report or review your analysis history.

 Important Notes

- The matching score measures text similarity; it is not a probability of getting hired.
- Suggestions are rule-based and are not generated by a large language model.
- Scanned PDFs may require OCR or manually entered resume text.
- This is an educational project. Authentication and local data storage should be strengthened before production use.
- Do not upload real resumes, passwords, or private database files to GitHub.
